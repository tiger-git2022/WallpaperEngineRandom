# Steam信息流（安卓）更新记录

Steam信息流（原名 Steam壁纸 / SteamWallpaper）：Steam 新闻流 + 关注的发行商新发售的时间线，以及浏览 Steam 上关注的作者的
Wallpaper Engine 壁纸、直接订阅（由电脑上的 Steam 下载）。版本号独立于电脑版，
代码在 WallpaperEngineRandom 仓库的 android/ 里，发布在同一个仓库的 Releases 里，标签为 `android-v版本号`。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。
最上面一节标了日期、合并到 main 后自动发布；标「未发布」时只编译。

## [0.4.0] - 2026-11-11

### 新增
- App 改名「Steam信息流」，加了「新闻」标签页（放在最前面），功能和电脑版 SteamNewsFeed 一样：
  - Steam 新闻中心的新闻流（和新闻中心一样的默认筛选：只因为 Steam「精选」才出现的热门游戏新闻不显示，设置里可以打开）；
  - 关注的发行商 / 开发商新发售的游戏（已经正式发售才算）：新闻流里有发售新闻就在那条上标「新发售」并附上游戏卡片，
    游戏页上有就把那条推过来，都没有就生成一张「《游戏名》 – 现已正式发售！」；
  - 阅读进度：比上次读到的新的标「新」，往下滚把它滚出屏幕顶部才算看过；「上次看到这里」分界线在离开 App 时记下，
    手动刷新后先隐藏；下次打开回到上次看到的位置；点「新闻」标签回到顶部（同时全部记为已读），在顶部再点就刷新；
  - 点标题或摘要展开全文（图片、视频、链接都在 App 里显示），有评论的直接显示最新几条，可以继续往下看；
  - 多个账号发的同一篇只显示一条，注明「XX 也发了」；每条右上角的「⋯」可以屏蔽游戏或账号，在新闻设置里取消；
  - 游戏卡片：价格按账号的商店地区（比如卢布），后面按当天汇率换算人民币；评测等级、好评率、好评数；加入 / 移出愿望单；
  - 右上角可以在浏览器打开；下次打开先显示上次的内容，后台再刷新（默认超过 30 分钟才刷新，可以改）。
- 新图标：和电脑版 SteamNewsFeed 一样的新闻卡片 + 橙点，纯色蓝底（矢量，各种屏幕都清楚；安卓 13 的主题图标也支持）。

### 改进
- 原来的「时间线」标签改名「壁纸动态」。

## [0.1.0] - 2026-11-10

### 新增
- 第一个版本，功能和电脑版 1.2.0 的「创意工坊」页一样，界面用原生 Compose 重写，顶栏、标签栏和面板是液态玻璃：
  - 时间线：在 Steam 上关注的作者发布的新壁纸，一条一条按时间排列；可以在设置里把同一作者 6 小时内的连续上传合成一条（最多 4 张）。先显示静态大图，动图下载好后自动换上。
  - 浏览进度：没看过的标 NEW，标签栏显示未读数，有「以下是已经看过的」分隔线；每次打开回到上次看到的位置。
  - 下拉刷新；点一下当前标签回到顶部（时间线同时全部记为已读），在顶部再点一下刷新；时间线标题旁有「全部已读」。
  - 浏览 / 搜索创意工坊：按类型、年龄分级、分辨率、标签筛选，按热度、最新、订阅数等排序。
  - 详情面板：大图和附加预览、标签、简介、评论，直接订阅 / 取消订阅（电脑上的 Steam 客户端自动下载）。
  - 作者页：作者上传的全部壁纸，可以关注 / 取消关注；「关注的作者」列表。
  - 在 App 里打开 Steam 官方登录页登录，可以退出登录。
  - 液态玻璃的模糊、不透明度和边缘色差可以在账号面板里调，所有玻璃一起变；跟随系统深浅色，文字一律黑色 / 白色。
  - 应用内检查更新，下载后直接安装。
